# CompassCrew Tutorial

## Quickstart

1. Install via the build instructions in [`README.md`](README.md) or [`INSTALL.md`](INSTALL.md).
2. Open the command palette, run **CompassCrew: doctor** — installs any missing companion plugins.
3. Run **CompassCrew: install canonical configs** — drops linter + breadcrumbs configs into place.
4. Right-click any folder → **CompassCrew: pollinate** to draw it as a canvas.
5. Open the **Live Panel** (command palette) to watch agent crews work.
6. Try **CompassCrew: scan and propose bearings** on a note to see AI-suggested N/S/E/W connections.

## Shortcuts

| Hotkey         | Action                                |
|----------------|----------------------------------------|
| Cmd+Shift+H    | Highlight selection with a bearing     |
| Cmd+Shift+C    | Copy trail-ref to clipboard            |
| Cmd+Shift+S    | Toggle all trail-refs (show/hide)      |
| Cmd+Click      | Peek destination in adjacent pane (native) |
| Shift+Click    | Collapse/expand a single trail-ref     |
