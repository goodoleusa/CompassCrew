## Quickstart

1. Install via the build instructions in `README.md`.
2. Open command palette, run **Faerie: doctor** — install any missing peers.
3. Run **Faerie: install canonical configs** — drops linter + breadcrumbs
   configs into place.
4. Run **Faerie: install QuickAdd macros** — populates
   `00-SHARED/QuickAdd-Macros/` with charter/manifest/anchor/honey macros.
5. Open the **Faerie Live** side pane (command palette).
6. Try **Faerie: highlight selection with bearing** on some text → pick N.
